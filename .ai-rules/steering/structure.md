## Main Library (`Onnx.Runtime.Embedder`)

Each file corresponds to one responsibility in the pipeline:

| File | Role |
|---|---|
| `OnnxEmbedder.cs` | Top-level `IEmbedder` implementation; orchestrates the full pipeline. Also defines `IEmbedderInfo` and `EmbedderInfo`. |
| `EmbedderBootstrapFactory.cs` | Factory entry point. Wires all pipeline components from `EmbedderFactoryOptions`. |
| `ModelContractResolver.cs` | Inspects ONNX session metadata to auto-discover input/output names and output dimensionality. |
| `IInferenceEngine.cs` | `IInferenceEngine` interface + `InferenceEngine` implementation wrapping `InferenceSession`. Also defines `ModelInfo`. |
| `Tokenizer.cs` | `ITokenizer` interface, `TokenizerResult` record, `FastTokenizer` (HuggingFace), `WordPieceTokenizer` (stub). |
| `Tensorizer.cs` | `IOnnxTensorizer` / `ITensorizer` interfaces + `Tensorizer` implementation. Converts token IDs to `NamedOnnxValue[]`. |
| `ClsMeanPooler.cs` | `IMeanPooler` interface, `ClsTokenPooler`, and `MaskedMeanPooler` implementations. |
| `L2VectorNormalizer.cs` | `IVectorNormalizer` interface + `L2VectorNormalizer` implementation. |

## Test Project (`Onnx.Runtime.Embedder.Test`)

| Path | Role |
|---|---|
| `Integration/` | Integration tests that run the full pipeline against real ONNX models |
| `Assets/PyTorch/` | Reference vectors generated by PyTorch, used to validate .NET output parity |
| `AssertVector.cs` | Shared test helpers for vector assertions (normalized, cosine similarity, dot product) |
| `TestHelper.cs` | Resolves the `.assets/` path relative to the test output directory |

## Conventions

- **One interface per pipeline stage** — always program to the interface (`IEmbedder`, `ITokenizer`, `IOnnxTensorizer`, `IMeanPooler`, `IVectorNormalizer`)
- **Namespace** matches the project root namespace: `Onnx.Runtime.Embedder` (main), `Onnx.Runtime.Embedder.Test` (tests)
- **Options objects** (e.g., `EmbedderFactoryOptions`, `TensorCreationOptions`) are plain classes used for configuration; keep them separate from logic classes
- **Info objects** (e.g., `ModelInfo`, `TokenizerInfo`, `EmbedderInfo`) are plain data containers returned by `GetInfo()` methods
- **`IDisposable`** must be implemented on any class that holds an `InferenceSession` or other native resource
- Integration tests are tagged with `[Category("Integration")]` and depend on model files in `.assets/`; they will fail if model files are absent
- New pooling strategies go in `ClsMeanPooler.cs` alongside existing implementations; new normalizers go in a similarly named file
